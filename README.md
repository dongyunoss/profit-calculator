# 자산운용 수익률 관리 (Profit Calculator)

자산 운용자가 여러 계좌의 수익률을 펀드 기준가 방식으로 관리하는 웹사이트입니다.
서버 없이 브라우저만으로 동작하며, 데이터는 브라우저 localStorage에 저장됩니다.

## 실행 방법

`index.html`을 브라우저로 열면 바로 사용할 수 있습니다.

로컬 서버로 띄우려면:

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

## 주요 기능

| 기능 | 설명 |
|------|------|
| 계좌별 기준가·좌수 | 기준가는 1,000좌당 가격, 개설 시 1,000.00 시작. 일일 평가금액 입력 시 `기준가 = 평가금액 × 1000 ÷ 좌수` 로 갱신 |
| 계좌별 수익률 | 기준가 수익률(계약 기준 — 보수 수취·재계약 후 기산), 원금대비 수익률, 누적 성과 수익률(보수 수취·재계약 무관) |
| 계좌 상세 원장 | 계좌를 선택하면 **원금 원장**(원금 → 추가입금·출금)과 **일별 평가·수익률**(일자·평가금액·원금대비 수익률·일간 수익률)을 2단으로 표시 |
| 입출금 | 현재 기준가로 좌수를 발행/환매 → 입출금이 수익률을 왜곡하지 않음 |
| 전액 출금(해지) | 현재 평가금액 전액을 출금하고 계좌를 해지 상태로 전환. 원금 음수 없이 정리되며, 해지 시점까지의 성과는 종합 성과 수익률에 보존됨 |
| 성과보수 수취 | 보수액 차감 후 기준가 1,000 / 수익률 0%로 초기화. **원금(순입금)은 보수로 줄지 않으며**, 전체 실적 수익률에도 보수가 다시 가산되어 수익률이 깎이지 않음 |
| 만기 · 재계약(Rollover) | 예금·채권·ELS·펀드의 만기 처리 방식을 그대로 반영. **만기 평가**(원리금·상환금), **이익 지급**(이자·쿠폰·배당), **재계약**(원리금 재예치 / 원금만 재예치) 지원 |
| 종합 성과 수익률 | 계좌별 일간 기준가 수익률을 직전 평가금액 가중으로 체인링크한 컴포지트 지수 (1,000 시작) |
| 원금대비 단순 수익률 | (총 평가금액 + 누적 성과보수 + 누적 이익지급 − 총 원금) ÷ 총 원금 — 이미 지급·수취되어 계좌 밖으로 나간 성과를 되살려, 보수 수취·재계약으로 전체 수익률이 깎여 보이지 않게 함 |
| 수익률 추이 차트 | 종합 성과 지수 / 계좌별 누적 수익률을 인라인 SVG 라인 차트로 시각화. 계좌별 보기에서 **범례의 계좌명을 클릭하면 해당 계좌만** 표시(다시 클릭 시 전체) |
| 계좌 이름 변경 | 계좌를 선택하면 상세 창 제목 옆 연필(✎) 아이콘으로 이름 변경 |
| 계좌 순서 변경 | 계좌 목록의 행을 **끌어서(드래그) 놓아** 순서 변경. 순서는 저장되어 요약·차트·엑셀에도 동일하게 반영 |
| 엑셀 다운로드 | 종합요약 + 종합지수 시계열 + 계좌별 거래·평가 이력을 .xlsx로 저장 (외부 라이브러리 없이 자체 생성) |
| 원금 입출금 내역 | '원금 입출금 내역' 버튼 → 전 계좌 집계·통합 내역과 **계좌별 원금 원장**을 계좌별 열로 나란히 표시. 엑셀에도 '원금원장' 시트로 포함 |
| 백업/복원 | 전체 데이터를 JSON으로 내려받고 복원 |

## 사용 흐름

1. **계좌 추가** — 계좌명, 개설일, 초기 원금을 입력합니다.
2. **일일 평가금액 입력** — 영업일 장 마감 후 각 계좌의 평가금액을 입력합니다.
   같은 날짜에 다시 입력하면 덮어씁니다.
3. **입출금** — 원금 입출금이 있으면 입력합니다. 현재 기준가로 좌수가 증감되어
   성과 측정이 왜곡되지 않습니다.
4. **성과보수 수취** — 보수액을 입력하면 평가금액에서 차감된 뒤 기준가와 수익률이
   초기화됩니다 (하이워터마크 리셋). 원금은 줄어들지 않습니다.
5. **만기 · 재계약** — 만기가 도래하면 아래 순서로 처리합니다.
   1. **만기 평가**로 만기 시점의 원리금(상환금)을 입력합니다 → 계좌가 *만기 도래* 로 표시됩니다.
   2. 이어서 후속 처리를 선택합니다.
      - **재계약 — 원리금 재예치**: 원리금 전액을 새 계약 원금으로 승계 (복리 재투자)
      - **재계약 — 원금만**: 이익(평가금액 − 원금)을 지급하고 원금만 재예치
      - **전액 출금(해지)**: 원리금을 모두 출금하고 계좌를 해지
   3. 만기 전 중도 이자·쿠폰·배당을 받았다면 **이익 지급**으로 입력합니다.
6. **엑셀 다운로드** — 전체 현황을 .xlsx 파일로 내려받습니다.

## 계산 규칙

- 같은 날짜의 입금/출금/평가는 **입력한 순서대로** 처리됩니다 (실제 발생 순서와 일치).
  - 입금을 먼저 기입하고 평가금액(입금 포함 잔고)을 나중에 입력 → 입금은 직전 기준가로 반영
  - 평가금액을 먼저 입력하고 입금을 나중에 기입(장 마감 후 입금 등) → 입금은 그날 갱신된
    기준가로 반영되어 **수익률이 희석되지 않습니다**
- **성과보수·이익 지급은 입력 순서와 무관하게 당일 평가 반영 후**에 처리됩니다.
  보수를 먼저 수취하고 평가금액을 나중에 입력해도 기준가 수익률은 정확히 0%로 초기화되고,
  종합 성과 수익률은 오염되지 않습니다. 당일 평가금액은 **보수 차감 전** 금액으로 입력하세요.
- **전액 출금(해지)은 그날의 가장 마지막**(보수 처리 후)에 처리됩니다. 같은 날 "평가 →
  보수 수취 → 전액 출금"을 함께 입력해도 순서가 보장됩니다. 해지된 계좌는 이후 종합 성과
  수익률 가중치에서 제외되며, 해지 시점까지의 성과는 지수에 그대로 남습니다. 해지 후
  다시 입금하면 기준가 1,000에서 새로 시작합니다.
- 입금: `추가 좌수 = 입금액 × 1000 ÷ 기준가`, 출금: `차감 좌수 = 출금액 × 1000 ÷ 기준가`
- 성과보수는 성과가 아닌 자금 유출(flow)로 처리되어 누적 성과 수익률을 훼손하지 않습니다.
- 종합(컴포지트) 일간 수익률: 해당 일자에 평가가 없는 계좌는 수익률 0으로,
  직전 평가금액만큼 가중치에 포함됩니다.

### 만기 · 재계약(Rollover) 회계

실물 자산의 만기 처리 관행을 이벤트로 옮긴 것입니다.

| 자산 | 만기 시 처리 | 이 앱에서의 입력 |
|------|-------------|-----------------|
| 예금 | 만기 원리금 확정 → 원리금 재예치 / 원금만 재예치(이자 수령) / 해지 | 만기 평가 → 재계약(원리금 또는 원금만) / 전액 출금 |
| 채권 | 이표(쿠폰) 수령, 만기 상환(액면 + 최종이자) | 이익 지급(쿠폰) · 만기 평가 → 재계약 / 전액 출금 |
| ELS | 조기·만기 상환(원금 + 쿠폰) 또는 손실 상환 | 만기 평가(상환금) → 재계약 / 전액 출금 |
| 펀드(폐쇄형) | 만기 청산·상환 | 만기 평가 → 재계약(재설정) / 전액 출금 |

- **만기 평가**는 만기 시점의 원리금(상환금)을 평가금액으로 입력하는 이벤트입니다.
  일반 평가와 동일하게 기준가·성과에 반영되고, 후속 처리(재계약·해지) 전까지
  계좌가 **만기 도래** 상태로 표시됩니다.
- **이익 지급**(이자·쿠폰·배당·상환수익)은 출금과 같은 자금 유출로 처리되어
  기준가 수익률을 왜곡하지 않으며, **원금(순입금)도 줄이지 않습니다**(성과보수와 같은 취급).
- **재계약**은 새 계약의 시작이므로 기준가를 1,000으로 되돌려 계약 기준 수익률을 0%로
  초기화합니다.
  - `원리금 재예치` — 원리금 전액을 새 계약 원금으로 승계 (평가금액 그대로)
  - `원금만` — 이익(평가금액 − 원금)을 지급한 뒤 원금만 재예치 (지급액 자동 계산)
- **개별 계좌는 초기화되지만 전체 실적은 유지됩니다.** 누적 성과 수익률과 종합 성과 지수는
  재계약과 무관하게 이어지고, 지급된 이익·수취한 보수는 원금대비 단순 수익률에 다시
  가산되므로 전체 수익률이 깎여 보이지 않습니다.
- 같은 날짜의 처리 순서는 **평가·만기(입력 순서) → 이익 지급·성과보수 → 재계약 →
  전액 출금**으로 보장됩니다. 재계약을 먼저 기입하고 만기 평가를 나중에 입력해도
  정확히 처리됩니다.

## 프로젝트 구조

```
index.html          # 화면
css/styles.css      # 스타일
js/engine.js        # 기준가/좌수 계산 엔진 (순수 함수, 테스트 가능)
js/xlsx-writer.js   # 의존성 없는 경량 .xlsx 생성기
js/chart.js         # 의존성 없는 인라인 SVG 라인 차트 (수익률 추이)
js/app.js           # 화면 렌더링·이벤트 처리·저장
tests/engine.test.js# 계산 검증 테스트
```

## 테스트

```bash
node tests/engine.test.js
```
